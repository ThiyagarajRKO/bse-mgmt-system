================================================================================
  VALIDATION FUNCTIONS AVAILABLE
================================================================================

1. validateGrade(grade, size, speciesType, productForm)
   → Checks if specific grade allowed for size/species/form
   → Returns: {valid, allowed_grades, reason, market_segment}

2. getAllowedGrades(size, speciesType, productForm)
   → Lists all permitted grades for size/species/form
   → Returns: {grades[], size_range, reason}

3. checkBlockStatus(size, speciesType, productForm)
   → Checks if size range is blocked (scrap/trim only)
   → Returns: {is_blocked, reason, size_range}

4. getRulesForSpeciesForm(speciesType, productForm)
   → Gets all size tiers for species/form combination
   → Returns: Array of rule objects

5. getSizeTiers(speciesType, productForm)
   → Returns tiered sizes with premium grades and market segments
   → Returns: Array with tier_name, size_range, allowed_grades
