## 🔍 Detailed Consolidation Steps

### **Step 1: Verify Duplication** (5 minutes)

Check that `20260109-seed-raw-material-products.js` truly duplicates main seeder:

```javascript
// File: 20260109-generate-products-from-mappings.js
// Step 7: Raw material generation - ALREADY DOES THIS

// File: 20260109-seed-raw-material-products.js
// DUPLICATE - Creates same raw materials again

// Both generate:
// - processing_state = 'RAW'
// - is_raw = true
// - product_role = 'RAW_MATERIAL'
// - is_producible = false
// - is_saleable = true
```

**Verification SQL:**

```sql
-- Check if raw products already generated by main seeder
SELECT COUNT(*) as raw_product_count
FROM product_master
WHERE is_raw = true AND is_active = true;

-- If > 0, main seeder already created raw materials
-- No need to run 20260109-seed-raw-material-products.js
```

### **Phase 5: Verify Consolidated Setup** (10 min)

Run verification queries to confirm proper consolidation:

```sql
-- 1. Check base data population
SELECT
  (SELECT COUNT(*) FROM species_master) as species_count,
  (SELECT COUNT(*) FROM product_category_master) as category_count,
  (SELECT COUNT(*) FROM size_master) as size_count,
  (SELECT COUNT(*) FROM grade_master) as grade_count;

-- Expected: All > 0 (species: 40+, categories: 50+, sizes: 10+, grades: 5+)

-- 2. Check product generation (Phase 2 seeder)
SELECT
  COUNT(*) as total_products,
  SUM(CASE WHEN is_raw = false THEN 1 ELSE 0 END) as processed_count,
  SUM(CASE WHEN is_raw = true THEN 1 ELSE 0 END) as raw_count
FROM product_master
WHERE is_active = true;

-- Expected: total ~2000+, processed ~1850, raw ~200+

-- 3. Check no duplicate raw products
-- (would indicate both seeders ran)
SELECT product_name, COUNT(*) as count
FROM product_master
WHERE is_raw = true
GROUP BY product_name
HAVING COUNT(*) > 1;

-- Expected: Empty result set (no duplicates)

-- 4. Check GST mapping
SELECT
  COUNT(*) as gst_mappings,
  COUNT(DISTINCT product_id) as products_with_gst
FROM product_taxcode_gst_mapping;

-- Expected: gst_mappings = all active products, products_with_gst = product count

-- 5. Check tax code mapping
SELECT
  COUNT(*) as tax_code_mappings,
  COUNT(DISTINCT taxcode_id) as unique_taxcodes
FROM taxcode_gst_mapping;

-- Expected: tax_code_mappings > 0
```

## 📝 Seeder Responsibilities (After Consolidation)

### **Seeder 1: Base Product Data**

**File:** `20251201-consolidated-product-master-seeder.js`

- **Responsibility:** Populate all master tables (species, categories, sizes, grades, derivatives)
- **Output:** ~40 species, ~50 categories, ~10 sizes, ~5 grades
- **Runtime:** ~100-200ms
- **Idempotent:** ✅ Yes (checks before insert)

### **Seeder 2: Complex Product Generation**

**File:** `20260109-generate-products-from-mappings.js`

- **Responsibility:** Generate all products from 4D mappings (both processed & raw)
- **Output:** ~2,000 products (~1,850 processed + ~200 raw)
- **Runtime:** ~300-400ms
- **Idempotent:** ✅ Yes (checks existing before insert)

### **Seeder 3: Tax/GST Mapping**

**File:** `20251212000000-seed-all-product-gst-mappings.js`

- **Responsibility:** Link all products to appropriate GST codes
- **Output:** ~2,000 tax mappings
- **Runtime:** ~100-150ms
- **Idempotent:** ✅ Yes (upsert operation)

### **Seeder 4: Tax Code Mapping**

**File:** `20251206000001-product-taxcode-gst-mapping.js`

- **Responsibility:** Maintain tax code to GST rate mappings
- **Output:** ~30-50 tax code mappings
- **Runtime:** ~50-100ms
- **Idempotent:** ✅ Yes (upsert operation)
