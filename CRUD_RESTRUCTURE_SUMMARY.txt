🔄 STANDARD CRUD FLOW
═══════════════════════════════════════════════════════════════════════════════

  CREATE                 → POST   /endpoint
                         → create.js handles POST requests
                         → Returns: 201 Created with data

  READ ALL               → GET    /endpoint?page=1&limit=10&filters
                         → getAll.js handles paginated list with filters
                         → Returns: 200 with data + pagination info

  READ ONE               → GET    /endpoint/:id
                         → get.js handles single record retrieval
                         → Returns: 200 with data or 404 Not Found

  UPDATE                 → PUT    /endpoint/:id
                         → update.js handles partial updates
                         → Returns: 200 with updated data
