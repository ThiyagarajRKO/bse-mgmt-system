## 🚀 Ready to Use

### API Endpoints

#### 1. Get Matching Raw Materials for Order Product
```bash
curl -X GET \
  "http://localhost:4000/api/order/product/matching-raw-materials/244f5f6c-5a14-4d52-be29-177d0f6af950" \
  -H "Cookie: sessionId=YOUR_SESSION"
```

**Returns:** All raw materials with the SAME species as the order product

#### 2. Get Raw Materials by Species
```bash
curl -X GET \
  "http://localhost:4000/api/purchase-inventory/by-species/8fe3b25f-9ba2-449e-91d1-11f0cd2253a0" \
  -H "Cookie: sessionId=YOUR_SESSION"
```

**Returns:** All raw materials for that specific species
